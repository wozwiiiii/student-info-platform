## 1. 问题域分析

### 1.1 产品定位与目标用户

【已确认·第 1 轮】
- **范围**：单一学校试点，跑通模式后再考虑复制
- **首批用户**：以低年级（大一、大二）为主
- **产品愿景**：让学生从大一开始就能看到完整的成长路径信息（竞赛、保研、实习、就业），形成详细成长规划

### 1.2 目标用户痛点

| 用户群 | 核心痛点 | 对本产品的诉求 |
|---|---|---|
| 低年级（首批核心） | 不知道大学四年该做什么、关键节点有哪些 | 【假设】需要一张「成长地图」 |
| 高年级（全周期覆盖） | 竞赛/保研/实习/就业信息靠口口相传，信息差=机会损失 | 结构化、及时、带截止提醒的机会信息 |
| 全体 | 信息分散、群消息淹没重要通知 | 统一入口 + 分类过滤 + deadline 提醒 |

### 1.3 信息类别与优先级

【已确认·第 2 轮】MVP 类别优先级排序如下：

| 优先级 | 类别 | 典型内容 | 获取难度 | 说明 |
|---|---|---|---|---|
| P0 | **机会成长类** | 竞赛/大创/科研招募、保研/考研/夏令营、实习/招聘/宣讲会 | 高（口口相传为主） | 愿景核心；内部含竞赛、升学、就业三条线 |
| P1 | **奖助评优类** | 奖学金、助学金、评优公示 | 中 | 全员关注，时效集中在申请季 |
| P2 | **学业教务类** | 选课、考试、成绩、教务通知 | 高（系统封闭） | MVP 阶段建议只做「通知转发」，不做系统对接 |
| P3（可选） | 讲座活动类 | 讲座、社团、文体活动 | 低 | 可包含也可忽略；公众号公开信息多、最易采集，可作补充填充 |

未被纳入 MVP：行政事务类（刚需低频，暂缓）。

客观提示：P0 类恰是采集难度最高的类别（v0.1 即识别的错配问题），**第 3 轮问答（数据来源）因此成为整个产品可行性的关键一轮**。

### 1.4 现有替代方案分析（不变，见 v0.1/v0.2）

差异化锚点：结构化 + 可信溯源 + deadline 提醒 + 成长视角。

## 3. MVP 功能范围（第 2 轮后初步收敛，数据来源待第 3 轮确认）

**MVP = 信息消费三件套 + 简版路线图 + 对应采集能力**

| 模块 | 内容 |
|---|---|
| 信息消费 | 统一信息流（A1）、分类频道（A2）、Deadline 日历（A3） |
| 成长规划 | 简版成长路线图（A4）：四年关键节点时间线 × 关联实时信息 |
| 信息类别 | P0 机会成长类（竞赛/升学/就业）> P1 奖助评优类 > P2 学业教务类（通知转发）；讲座活动类可选 |
| 信息采集 | 人工录入后台（B3）+ 内容结构化（B4）为基座；公众号接入/官网抓取方式待第 3 轮 |

**明确不进 MVP**：关键词订阅、精选摘要、学院/年级过滤、众包投稿、个性化推荐、社区功能、Web 端（后置到 V1/远期）。

## 4. 产品原则

1. **中台优先，不是社区优先**
2. **信息质量 > 信息数量**
3. **截止时间是第一公民**
4. **不做无来源信息**
5. **成长视角**：机会类信息按可前置规划的视角呈现（简版路线图承载）

## 5. 客观约束与风险

| # | 风险/约束 | 客观描述 | 应对方向 |
|---|---|---|---|
| R1 | **数据获取是最大瓶颈（MVP 关键风险）** | P0 机会成长类信息无结构化公开源；教务系统封闭；抓取有稳定性与规则风险。【待第 3 轮确认现实组合】 | 人工聚合为基座，技术手段为增强 |
| R2 | 冷启动运营成本高 | 采集需持续人工投入，易陷入负循环 | 单校聚焦 + 学生信息员机制（待第 5 轮） |
| R3 | 官方合作不确定 | 校方支持属假设非事实 | 不写入 MVP 前提 |
| R4 | ~~多校复用~~ | ✅ 已通过单校试点决策规避 | — |
| R5 | 习惯迁移成本 | 需明显更高价值密度 | deadline 提醒 + 路线图作为价值锚点 |
| R6 | 可持续性 | 学生团队更替常见 | 【待第 5 轮】 |
| R7 | 愿景与资源的张力 | P0 三条线（竞赛/升学/就业）同时起步采集压力大 | 【待第 3 轮】：确认三条线的信息来源现实性，必要时 MVP 内再排序 |
| R8 | **（新增）路线图内容的维护成本** | 简版路线图依赖人工整理四年节点知识，且政策/时间每年变化，存在内容过期风险 | 路线图节点标注「整理时间 + 待验证」；与实时信息流关联而非孤立存在 |

## 7. 已确认 / 假设 / 待确认 清单

**已确认**
- 产品定位：大学生信息收集与汇总数据中台（单校内）
- 信息源范围（至少包含）：校教务处、校学生会、校就业处、专业学院
- 范围：单一学校试点；首批用户低年级为主 + 全周期成长规划愿景（第 1 轮）
- MVP 信息类别优先级：机会成长类 > 奖助评优类 > 学业教务类（通知转发），讲座活动类可选（第 2 轮）
- 简版成长路线图进入 MVP（第 2 轮）

**假设（有依据但未验证）**
- 「分散/过载/易错过」痛点在目标学校普遍存在
- 低年级存在规划迷茫且愿意使用工具
- 目标学校当前无覆盖多源的同类工具
- 简版路线图的四年节点知识可由团队人工整理并保持更新

**待确认**
- Q3 数据来源与获取方式的现实组合；P0 三条线（竞赛/升学/就业）MVP 内是否再排序（第 3 轮，进行中）
- Q4 产品形态与触达渠道组合（第 4 轮）
- Q5 运营模式与信息可信机制（第 5 轮）
